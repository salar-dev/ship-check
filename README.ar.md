# Ship Check

سكِل مجاني لـ Claude يجهّز موقعك أو تطبيق الويب للإطلاق.

بنيت موقعاً بأدوات الذكاء الاصطناعي، ويعمل على حاسبتك. Ship Check يقرأ المشروع ويخبرك بكلام بسيط ما الذي يجب إصلاحه قبل وصول الزوار الحقيقيين، ثم يساعدك على إصلاحه.

[English](README.md)

## ماذا يفعل

اكتب `/ship-check` في Claude Code واختر واحداً من خمسة أوضاع:

| الوضع | ما تحصل عليه |
|---|---|
| **Launch check** (فحص الإطلاق) | تقرير بالأحمر والأصفر والأخضر للأخطاء التي تضرّ عند الإطلاق: مفاتيح مكشوفة، صفحات وبيانات يصلها أي شخص، مدخلات بلا تحقق، وحمايات ناقصة. 28 فحصاً. |
| **Bug hunt** (صيد الأخطاء) | ما هو معطّل أو سيتعطّل عند الزوار الحقيقيين، والأشد ضرراً أولاً. |
| **Code cleanup** (ترتيب الكود) | مشروع أسهل في التعديل دون أن ينكسر. الموقع يبقى يعمل كما هو. |
| **UI review** (مراجعة الواجهة) | التخطيط، وضوح القراءة، الهواتف، حالات التحميل والخطأ. ألوانك وتصميمك تبقى كما هي. |
| **Go live** (خطة النشر) | خطة خطوة بخطوة للانتقال من حاسبتك إلى الإنترنت: الاستضافة، قاعدة البيانات، تسجيل الدخول، الذكاء الاصطناعي، الدفع، النطاق. كل خطوة مكتوب عليها من ينفّذها: أنت أم Claude. |

تقرير فحص الإطلاق ينتهي بقسم اسمه **Start here**. يجمع المشاكل حسب سببها ويرتّبها، فتتحول القائمة الطويلة إلى أشياء قليلة تصلحها.

## ما لا يفعله

- **لا يغيّر شيئاً دون موافقتك.** الفحص لا يعدّل مشروعك. الإصلاحات تتم واحداً واحداً، بعد أن تختارها.
- **لا يلمس موقعك المنشور.** يعمل على نسختك المحلية فقط.
- **لا يُظهر أسرارك.** لا يفتح ملفات الإعدادات، وأي مفتاح يجده في الكود يظهر مخفياً في التقرير.
- **لا يقول لك إن الموقع آمن.** Ship Check فحص وليس ضماناً. يلتقط الأخطاء الشائعة بقراءة الكود. ليس تدقيقاً أمنياً، ولا يستطيع إثبات أن الموقع آمن. أفضل نتيجة يعطيها: «لم تجد هذه الفحوصات مشاكل».

## التثبيت

تحتاج [Claude Code](https://claude.com/claude-code). وجود Python 3 يجعل الفحص الأول أسرع، لكن السكِل يعمل بدونه.

**يدوياً**

1. في هذه الصفحة اضغط **Code** ثم **Download ZIP**، وفكّ الضغط.
2. انقل المجلد الذي اسمه `ship-check` إلى مجلد السكِلات الخاص بـ Claude:
   - macOS و Linux: <code dir="ltr">~/.claude/skills/</code>
   - Windows: <code dir="ltr">%USERPROFILE%\.claude\skills\</code>

   أنشئ مجلد `skills` إن لم يكن موجوداً. النتيجة الصحيحة: <code dir="ltr">.claude/skills/ship-check/SKILL.md</code>

**بالطرفية (macOS و Linux)**

<div dir="ltr">

```bash
git clone https://github.com/salar-dev/ship-check.git /tmp/ship-check && mkdir -p ~/.claude/skills && cp -R /tmp/ship-check/ship-check ~/.claude/skills/
```

</div>

## الاستخدام

1. افتح مجلد مشروعك في Claude Code.
2. اكتب `/ship-check`. إن لم يظهر في القائمة فاكتب `/reload-skills` أو أعد تشغيل Claude Code.
3. اختر وضعاً، أو قل ما تريد مباشرة: «هل الموقع جاهز للإطلاق؟»، «أين أستضيفه؟».

إن كنت على وشك الإطلاق فالترتيب المفيد: فحص الإطلاق، ثم إصلاح الأحمر، ثم خطة النشر.

## معلومات مفيدة

- السكِل غير مرتبط بتقنية واحدة. إن ظهرت نتيجة غريبة في مشروعك، فافتح Issue هنا.
- الملفات التي يكتبها السكِل (التقرير وخطة النشر) بالإنجليزية، حتى يقرأها أي مبرمج. والمحادثة تتبع لغتك.
- أسعار الاستضافة والخدمات وحدودها تتغيّر. السكِل يطلب منك تأكيدها من صفحة الخدمة نفسها.
